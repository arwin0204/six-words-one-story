A deterministic Node program that writes one original six-word story to `/output/entry.txt` for make.fun's "Six Words, One Story" bounty: **"Grandma's recipe died with her. Almost."** — a whole life, a loss, and a last-word turn, in exactly six words.

## Run it

```sh
node main.ts
```
